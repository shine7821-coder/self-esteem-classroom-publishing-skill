# 연재 편성표

## 기본 주간 편성
| 요일 | 플랫폼 | 목적 | 콘텐츠 |
|---|---|---|---|
| 월 | Threads | 관계 | 실제 교실 관찰 한 장면 |
| 화 | Instagram | 발견·공감 | 핵심 문장/공감 카드 |
| 수 | Blog | 신뢰·검색 | 실제 사례 + 상세 교수법 |
| 목 | Threads | 댓글 | 선택형 질문/독자 고민 |
| 금 | Instagram | 저장·공유 | 오늘 바로 써보세요/자료 팁 |
| 토 | Threads | 인간적 연결 | 교사의 고민 또는 짧은 성찰 |
| 일 | Brunch | 작가성 | 깊은 교육 에세이 |

## 월간 구조
### 1주차
문제 제기: 아이에게 어떤 경험이 필요한가?

### 2주차
실제 사례: 교실에서 무엇이 일어났는가?

### 3주차
실용 적용: 어떻게 수업을 설계할 것인가?

### 4주차
참여/챌린지: 독자가 직접 해보고 결과를 나눈다.

## 시즌 예시
1. 아이를 바라보는 눈
2. 자존감은 관계에서 자란다
3. 좋은 수업에 대한 질문
4. 자존감이 실력으로 이어지는 실제 교실
5. 배우는 교사

## 한 주의 재활용 원칙
하나의 핵심 주제에서 최소 4개의 서로 다른 결과물을 만든다.
- Brunch: 전체 생각
- Instagram: 가장 강한 문장과 시각적 구조
- Blog: 상세 사례와 실행법
- Threads: 대화를 여는 질문
