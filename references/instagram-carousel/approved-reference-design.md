# Approved Instagram Carousel Reference Design

이 문서는 현재 승인된 카드뉴스 디자인을 **시각적 레퍼런스 디자인**으로 정의한다. Instagram 카드뉴스 제작 시 `rules/instagram-carousel.md`와 함께 참고한다.

## Reference status
- 상태: **Approved / Primary reference**
- 용도: 북스타 영어·《자존감 교실》 인스타그램 카드뉴스의 기본 시각 기준
- 기본 규격: **1080×1350px / 4:5 / PNG**
- 기준 감정: 따뜻함, 공감, 작은 용기, 아이의 성취 경험, 교사의 다정한 관찰
- 기본 캐릭터 체계: **Charlie Brown(찰리브라운) + 필요 시 Snoopy(스누피)**

## Visual fingerprint

### Background
- 밝은 연크림·연베이지·연주황 계열
- 거의 단색처럼 느껴지는 잔잔한 톤
- 사진 배경, 복잡한 패턴, 강한 그라데이션 금지

### Typography
- 검정 또는 아주 짙은 브라운
- 굵고 둥글며 친근한 한국어 글자
- 한 장에 짧은 문장 중심
- 넓은 행간과 큰 글자
- 오렌지색으로 일부 단어, 따옴표, 밑줄만 강조

### Page number
- 왼쪽 위 짙은 브라운 원형 배지
- 안쪽 숫자는 흰색
- 모든 카드에서 위치와 크기를 일정하게 유지

### Approved character reference
- 이 시리즈의 기본 주인공은 **Charlie Brown**이다.
- 장면상 필요할 경우 **Snoopy**를 함께 배치한다.
- Charlie Brown의 기본 외형은 다음 요소를 일관되게 유지한다.
  - 둥근 머리와 작은 앞머리 컬
  - 단순한 눈·코·입 선
  - 노란 셔츠와 검은 지그재그 무늬
  - 검은 반바지
  - 노란 계열 양말
  - 갈색 신발
  - 검은 손그림 윤곽선
- Snoopy의 기본 외형은 다음 요소를 유지한다.
  - 흰색 몸
  - 검은 귀와 코
  - 단순한 얼굴선
  - 작고 둥근 몸 비율
- 카드마다 표정과 자세는 달라질 수 있지만, **같은 캐릭터가 연속 장면에 등장하는 것처럼 보여야 한다.**
- 새 카드 제작 또는 일부 카드 재생성 시, 이전 승인 카드 중 가장 유사한 장면을 참조해 캐릭터 형태와 색감을 맞춘다.
- 캐릭터는 문장의 감정을 보조하며 텍스트를 압도하지 않는다.

### Character consistency anchors
특히 아래 시각 요소는 시리즈 전체에서 흔들리지 않게 한다.
1. 얼굴/머리 비율
2. 노란 셔츠의 지그재그 패턴
3. 반바지·양말·신발 색감
4. 검은 윤곽선의 굵기와 손그림 느낌
5. Charlie Brown과 Snoopy의 상대적 크기
6. 따뜻한 표정 톤

### Supporting objects
- 짧은 풀, 별, 하트, 생각 구름, 책상, 책, 개집 등은 최소한으로 사용한다.
- 오브젝트는 한 장의 메시지를 설명하는 데 필요한 경우에만 넣는다.

### Layout
- 텍스트는 주로 좌측 또는 상단
- 캐릭터는 우측 또는 하단에 배치
- 화면의 상당 부분을 여백으로 남김
- 요소끼리 겹치지 않게 배치
- 외곽 테두리, 카드 사이 흰 선, 다른 카드 일부 노출 금지

## Approved carousel feeling
첫 장은 큰 문장과 Charlie Brown의 작은 장면만으로 감정 훅을 만든다.

예시 감정 구조:
- 아이의 말: “선생님, 저는 영어를 하나도 몰라요.”
- 교사의 관찰: 아이는 수업 전부터 이미 ‘나는 못해’라고 결론 내림
- 관점 전환: 정말 모르는가, 아니면 못한다고 믿는가
- 수업 철학: 칭찬만이 아니라 작은 성공 경험이 필요함
- 변화: “어? 나도 할 수 있네!”
- 반복 구조: 작은 도전 → 반복 → 다시 해보기 → 성공 → 표현하기
- 핵심 메시지: “실력은 건강한 자존감 위에 세워진다.”

## Reference palette direction
정확한 HEX를 고정하기보다 다음 관계를 유지한다.
- Background: warm cream / pale peach
- Main text: near-black / dark brown
- Accent: vivid warm orange
- Charlie Brown shirt: muted warm yellow + black zigzag
- Shoes/number badge: dark brown
- Snoopy: white + black
- Optional accents: small red heart, muted green grass

## Production behavior
이 레퍼런스를 참고해 새 카드뉴스를 만들 때:
1. 레퍼런스의 **톤·여백·타이포 대비·페이지 번호 체계·캐릭터 크기감**을 우선 유지한다.
2. 주제에 맞춰 문장과 장면은 새롭게 구성한다.
3. **Charlie Brown을 기본 주인공으로 유지하고, 필요한 경우 Snoopy를 함께 사용한다.**
4. 새 카드 또는 수정 카드는 이전 승인 카드와 캐릭터 외형을 비교해 일관성을 확인한다.
5. 생성형 이미지에서 한글이 들어가면 오타 가능성을 전제로 반드시 카드별 검수한다.
6. 오타 수정본이 생기면 그 카드만 다시 수정하고, 최종 캐러셀·미리보기·ZIP을 수정본으로 재구성한다.
7. 일부 카드만 다시 만들 때는 기존 승인 카드 이미지를 레퍼런스로 넣어 Charlie Brown/Snoopy의 외형 편차를 최소화한다.

## Final benchmark checklist
새 디자인이 아래 질문에 모두 YES이면 레퍼런스와 충분히 일관된 것으로 본다.
- 첫눈에 따뜻한 연크림·연주황 톤인가?
- 검정/짙은 브라운 글자 + 오렌지 강조가 중심인가?
- 왼쪽 위에 브라운 원형 페이지 번호가 있는가?
- 한 장에 메시지가 하나인가?
- 여백이 충분한가?
- Charlie Brown이 시리즈 전체에서 같은 캐릭터로 보이는가?
- Snoopy가 등장할 경우 외형과 비율이 일관적인가?
- 캐릭터가 문장을 보조하고 있는가?
- 복잡한 장식 없이 조용하고 따뜻한가?
- 모든 카드가 정확히 1080×1350px인가?
- 한글 오타·잘림·파일 손상이 없는가?
