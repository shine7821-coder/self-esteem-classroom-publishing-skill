# Instagram Carousel Production Checklist

## User-request standard
- [ ] 요청 장수와 실제 카드 수가 동일하다.
- [ ] 카드마다 하나의 독립 PNG 파일이다.
- [ ] 여러 카드를 한 이미지에 합치지 않았다.
- [ ] 인접 카드의 일부가 섞이지 않았다.
- [ ] 모든 카드가 정확히 1080×1350px, 4:5이다.
- [ ] 모든 카드의 가로·세로 크기가 동일하다.
- [ ] 연주황/피치 단색 바탕과 브라운 계열 타이포그래피가 유지된다.
- [ ] 캐릭터와 오브젝트가 문장을 방해하지 않는다.
- [ ] 페이지 번호가 01, 02, 03… 순서로 정확하다.
- [ ] 한글 오타, 누락, 글자 잘림이 없다.
- [ ] PNG 파일이 정상적으로 열린다.
- [ ] 전체 PNG를 하나의 ZIP으로 묶는다.
- [ ] 파일명은 업로드 순서대로 정렬된다.
- [ ] 마지막 카드의 브랜드 서명은 사용자가 지정한 정확한 문구를 사용한다.

## Reference-sheet separation
1. 사용자가 제공한 레퍼런스 시트를 원본으로 사용한다.
2. 카드 사이의 흰색/배경 경계를 먼저 확인한다.
3. 각 카드의 경계 안에서만 crop한다.
4. crop 후 4:5 캔버스에 배치할 때 원본 콘텐츠를 찌그러뜨리지 않는다.
5. 필요한 경우 동일한 연주황 배경으로 여백을 채운다.
6. 최종 결과에서 옆 카드의 텍스트·그림·테두리가 들어오지 않았는지 확인한다.

## Preview
- 채팅 UI에서 지원되는 이미지 갤러리/캐러셀을 우선 사용한다.
- 실제 커스텀 스와이프 UI가 지원되지 않는 환경에서는 이를 지원한다고 주장하지 않는다.
- 별도의 외부 미리보기 사이트는 만들지 않는다.
- 게시용 PNG와 미리보기용 contact sheet를 혼동하지 않는다. contact sheet는 검수용일 뿐 게시용 파일이 아니다.
