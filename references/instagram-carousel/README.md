# Instagram Carousel Reference

## Primary approved reference
Instagram 카드뉴스 제작 시 아래 파일을 **우선 레퍼런스**로 사용한다.

- `approved-reference-design.md` — 현재 승인된 북스타/《자존감 교실》 카드뉴스의 시각 기준

핵심 인상:
- 따뜻한 연크림·연베이지·연주황 단색 계열 배경
- 검정/짙은 브라운 텍스트
- 오렌지 포인트
- 왼쪽 위 브라운 원형 페이지 번호
- 넓은 여백
- 단순한 손그림 카툰
- 짧고 감정이 분명한 한국어 문장
- 1080×1350px, 4:5 세로형

## Legacy panel references
기존 SVG 레퍼런스도 보조 자료로 남긴다.
- `carousel-01.svg` — 첫 장: 감정 훅
- `carousel-02.svg` — 감정 공감
- `carousel-03.svg` — 작은 일상 장면
- `carousel-04.svg` — 캐릭터와 관계
- `carousel-05.svg` — 핵심 위로 문장
- `carousel-06.svg` — 저장·공유 CTA

단, 기존 SVG와 새 승인 레퍼런스가 충돌할 경우 **`approved-reference-design.md`와 `rules/instagram-carousel.md`를 우선한다.**

## Production note
실제 게시용 이미지는 `rules/instagram-carousel.md`의 규칙에 따라 **장별 독립 PNG**로 제작한다. 여러 장을 한 게시용 이미지로 합치지 않는다.
