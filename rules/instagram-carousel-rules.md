# 인스타그램 캐러셀 규칙

> 이 파일은 호환성을 위해 남겨둔 legacy 안내 파일이다. 실제 제작 시에는 **`rules/instagram-carousel.md`를 최우선 규칙(source of truth)** 으로 사용하고, 시각적 판단은 **`references/instagram-carousel/approved-reference-design.md`** 를 함께 참고한다.

## 핵심 요약
- 4:5 세로형, **1080×1350px**
- 모든 카드는 동일한 크기
- 따뜻한 연크림·연베이지·연주황 계열 단색 배경
- 검정/짙은 브라운 텍스트 + 오렌지 포인트
- 왼쪽 위 브라운 원형 페이지 번호
- 짧은 문장, 넓은 여백
- **Charlie Brown(찰리브라운)을 시리즈의 기본 주인공으로 일관되게 사용**
- 필요 시 **Snoopy(스누피)** 를 함께 배치
- 카드 간 얼굴 비율, 노란 셔츠와 검은 지그재그 패턴, 반바지·양말·신발, 선 굵기와 색감의 연속성을 유지
- 일부 카드만 수정·재생성할 때는 기존 승인 카드를 레퍼런스로 사용해 Charlie Brown/Snoopy 외형 편차를 최소화
- 한 장에 하나의 핵심 메시지
- 카드별 독립 PNG 저장
- 여러 카드를 하나의 게시용 이미지로 합치지 않음
- 한글 오타, 페이지 번호, 글자 잘림, 카드 겹침, 흰색 구분선, PNG 손상 여부를 게시 전 전수 검수
- 수정 카드가 생기면 해당 카드를 교체한 뒤 전체 미리보기와 ZIP을 다시 구성
- 마지막 브랜드 표기는 현재 승인 기준 **“북스타 써니쌤”**

자세한 캐릭터 일관성 기준, 서사 구조, 10장/11장 재구성 방식, 한국어 QA, 최종 납품 규칙은 `rules/instagram-carousel.md`를 따른다.
