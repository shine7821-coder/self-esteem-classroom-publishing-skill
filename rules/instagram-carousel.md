# Instagram Carousel Design Rules

## Purpose
《자존감 교실》과 북스타 영어의 인스타그램 캐러셀은 **따뜻한 공감 → 짧은 문장 → 넓은 여백 → 작은 성취 경험 → 저장·공유·대화**의 흐름을 시각적으로 구현한다.

이 파일은 Instagram 카드뉴스 제작의 **최우선 제작 규칙(source of truth)** 이다. 디자인 판단이 애매할 때는 `references/instagram-carousel/approved-reference-design.md`의 승인 레퍼런스를 우선 참고한다.

---

## 1. Approved visual identity

### 기본 톤
- 세로형 **4:5, 1080×1350px**를 기본 규격으로 한다.
- 배경은 **따뜻한 연크림·연베이지·연주황 계열의 거의 단색에 가까운 톤**을 사용한다.
- 화면 전체에 사진, 복잡한 패턴, 강한 그라데이션, 장식 프레임을 넣지 않는다.
- 텍스트는 **검정 또는 아주 짙은 브라운**을 주색으로 한다.
- 강조색은 **오렌지 1색**을 중심으로 사용한다.
- 보조색은 캐릭터 의상·소품에 필요한 노랑, 브라운, 빨강, 초록 정도만 제한적으로 사용한다.

### 여백과 구도
- 한 카드에서 시선이 머무는 요소는 **텍스트 1블록 + 캐릭터/아이콘 1장면** 정도로 제한한다.
- 상하좌우 안전 여백을 충분히 확보한다.
- 텍스트·페이지 번호·캐릭터가 화면 끝에 닿거나 잘리지 않게 한다.
- 카드 사이에 흰색 구분선, 외곽 테두리, 다른 카드의 일부가 보이면 실패로 간주한다.
- 캐릭터는 메시지를 보조하는 조연으로 두고, 텍스트의 가독성을 방해하지 않게 한다.

### Character system — Charlie Brown consistency
- 이 캐러셀 시리즈의 **기본 주인공 캐릭터는 Charlie Brown(찰리브라운)** 으로 통일한다.
- 장면상 필요할 경우 **Snoopy(스누피)** 를 함께 배치한다.
- 같은 캐러셀 안에서는 Charlie Brown의 **얼굴 비율, 머리 형태와 앞머리 컬, 노란 셔츠와 검은 지그재그 무늬, 검은 반바지, 양말, 갈색 신발, 선 굵기와 색감**을 일관되게 유지한다.
- Snoopy를 사용할 경우에도 **흰색 몸, 검은 귀와 코, 단순한 선화, 캐릭터 비율**을 카드마다 일관되게 유지한다.
- 각 장의 감정에 따라 표정·시선·손동작·자세는 달라질 수 있지만, 기본 외형은 동일한 캐릭터로 보이게 한다.
- 새로운 카드를 생성하거나 일부 카드만 수정할 때는 **이전 승인 카드 중 가장 유사한 구도/표정의 카드를 시각 레퍼런스로 함께 사용**해 캐릭터 편차를 최소화한다.
- 오타 수정이나 재생성 때문에 특정 카드의 얼굴·체형·의상·선 느낌이 다른 카드와 달라지면 최종본으로 사용하지 않는다.
- 캐릭터는 화면을 과도하게 차지하지 않고, **문장의 감정을 보여주는 시각적 파트너** 역할을 한다.
- 그림은 지나치게 입체적이거나 사실적으로 만들지 않고, 승인 레퍼런스의 담백한 신문 카툰 감성을 유지한다.

### Character continuity checklist
카드 제작 또는 수정 시 다음을 비교한다.
1. 얼굴과 머리 비율이 이전 카드와 유사한가?
2. 노란 셔츠의 검은 지그재그 패턴이 유지되는가?
3. 반바지·양말·신발 색감이 동일한가?
4. 눈·코·입의 선 스타일이 카드마다 흔들리지 않는가?
5. Snoopy가 등장할 경우 크기·귀·코·몸 비율이 통일되어 있는가?
6. 캐릭터의 전체 채색과 검은 윤곽선 굵기가 시리즈 안에서 일관적인가?

## 2. Typography rules
- 한국어 본문은 **굵고 둥글며 손글씨 느낌이 약간 있는 고가독성 서체 분위기**를 사용한다.
- 한 장에 핵심 메시지는 1개만 둔다.
- 긴 문단 대신 1~4개의 짧은 행으로 나눈다.
- 행간은 넓게, 글자 간격은 답답하지 않게 한다.
- 강조는 한 장당 1~2곳만 사용한다.
- 강조 방식은 오렌지색 글자, 오렌지 따옴표, 오렌지 밑줄, 작은 하트/별 중 하나 정도로 제한한다.
- 문장은 말하듯 자연스럽고 따뜻한 한국어로 쓴다.
- **생성형 이미지 모델에 한글을 맡긴 경우 반드시 별도 오타 검수 단계를 거친다.**

---

## 3. Page-number system
- 각 카드 왼쪽 위에 **짙은 브라운 원형 배지 + 흰색 페이지 번호**를 둔다.
- 번호 위치, 원 크기, 숫자 크기는 전체 캐러셀에서 동일하게 유지한다.
- 페이지 번호는 `1 → 2 → 3 ...` 순서로 정확히 이어져야 한다.
- 카드 수를 재구성한 경우 최종 장수 기준으로 번호를 다시 검수한다.

## 4. Carousel storytelling structure
캐러셀은 6장, 8장, 10장, 11장 등 요청한 장수에 맞게 재구성할 수 있다. 장수보다 **서사 흐름**이 우선이다.

권장 흐름:
1. **Hook** — 아이·교사·부모의 실제 한마디 또는 강한 질문
2. **상황** — 이미 굳어진 생각 또는 어려움
3. **질문/관점 전환** — 정말 못하는가, 아니면 못한다고 믿는가
4. **문제의 핵심** — 틀림, 포기, 자존감 등
5. **변화의 순간** — “어? 나도 할 수 있네!”
6. **성취 경험 구조** — 작은 도전 → 반복 → 다시 해보기 → 성공 → 표현
7. **수업 원칙** — 작게, 천천히, 꾸준히
8. **핵심 철학** — “실력은 건강한 자존감 위에 세워진다.”
9. **참여 CTA** — 경험 공유, 저장, 질문
10. **다음 이야기 예고/브랜드 서명**

11장 버전에서는 4번과 5번 사이 또는 성취 경험 앞에 **칭찬만으로는 마음이 바뀌지 않는다는 보충 카드**를 넣을 수 있다.

## 5. Approved 10-card reference flow
현재 승인된 레퍼런스 카드뉴스의 핵심 문장 흐름은 다음과 같다.

1. “선생님, 저는 영어를 하나도 몰라요.”
2. “수업 시작 전, 아이는 이미 결론을 내렸어요.”
3. “정말 영어를 모르는 걸까? 아니면, ‘나는 못해’라고 믿게 된 걸까?”
4. “틀리는 순간 자신을 포기하는 아이들. 칭찬만으로 아이의 마음은 바뀌지 않아요.”
5. “아이가 달라지는 순간, ‘어? 나도 할 수 있네!’”
6. “필요한 건 경험!” — 작은 도전 / 반복 / 다시 해보기 / 성공 / 표현하기
7. “그래서 수업은 작게, 천천히, 꾸준히!”
8. “실력은 건강한 자존감 위에 세워진다.”
9. “여러분의 경험도 들려주세요!”
10. “다음 이야기 예고 — 아이에게는 ‘아직’이 필요하다” + `북스타 써니쌤 ❤`

이 흐름은 **문장 구조와 감정선의 레퍼런스**이며, 다른 주제 제작 시 문장을 그대로 복제할 필요는 없다. 캐릭터는 기본적으로 Charlie Brown을 유지하고, 필요에 따라 Snoopy를 함께 사용한다.

## 6. Production rules
- 최종 게시용 파일은 **모든 카드가 정확히 1080×1350px**이어야 한다.
- 출력 형식은 **PNG**를 기본으로 한다.
- 모든 카드의 가로·세로 크기는 완전히 동일해야 한다.
- 여러 카드를 하나의 게시용 이미지로 합치지 않는다.
- 각 카드는 독립 PNG로 저장한다.
- 파일명은 업로드 순서를 반영해 `bookstar_carousel_01.png`, `bookstar_carousel_02.png`처럼 번호순으로 만든다.
- 레퍼런스 시트에서 분리할 경우 카드 경계를 정확히 찾아 **인접 카드가 1px도 섞이지 않게** crop한다.
- 원본 비율이 4:5가 아니면, 텍스트나 캐릭터를 강제로 자르지 말고 동일한 배경 톤을 확장해 4:5에 맞춘다.
- 이미지 생성 결과가 4:5에 근접하지만 정확하지 않은 경우, 최종 단계에서 안전 영역을 보존한 채 1080×1350으로 정규화한다.
- 일부 카드만 다시 생성하는 경우, **승인된 기존 Charlie Brown 카드 이미지를 참조 이미지로 사용해 캐릭터 일관성을 우선한다.**
- 마지막 카드의 브랜드 표기는 사용자가 지정한 정확한 철자를 사용한다. 현재 승인 표기는 **“북스타 써니쌤”**이다.

## 7. Korean text QA — mandatory
게시 전 한글 텍스트는 이미지에 실제로 보이는 글자를 기준으로 **카드별 전수 검수**한다.

필수 체크:
1. 조사·어미·띄어쓰기 오류
2. 유사 글자 오생성 (`모로는` → `모르는` 같은 오류)
3. 따옴표·쉼표·마침표 누락
4. 받침 깨짐 또는 글자 합성 오류
5. 글자 잘림·겹침·찌그러짐
6. 원고와 이미지 문구가 정확히 일치하는지

오타가 발견되면:
- 해당 카드만 수정한다.
- 수정 카드의 디자인·레이아웃·색상·번호와 **Charlie Brown/Snoopy 외형**을 기존과 최대한 동일하게 유지한다.
- 수정본을 기존 카드와 교체한 뒤 **전체 캐러셀을 다시 재구성**한다.
- ZIP과 미리보기도 수정본 기준으로 다시 만든다.

---

## 8. Final asset QA — mandatory
최종 출력 후 다음을 확인한다.

1. 요청 장수와 실제 PNG 수가 일치하는가?
2. 모든 파일이 정확히 1080×1350px인가?
3. 모든 파일이 정상 PNG로 열리는가?
4. 카드 번호가 정확히 순서대로인가?
5. 한글 오타·누락·잘림이 없는가?
6. 인접 카드가 섞이거나 겹치지 않았는가?
7. 카드 상·하단에 의도하지 않은 흰색 띠나 구분선이 없는가?
8. 모든 카드의 배경 톤과 타이포그래피 체계가 통일되어 있는가?
9. Charlie Brown의 얼굴·의상·비율·선 느낌이 카드마다 일관적인가?
10. Snoopy가 등장하는 카드의 캐릭터 비율과 선화가 일관적인가?
11. 강조색이 오렌지 중심으로 일관적인가?
12. 마지막 카드의 서명/브랜드 문구 철자가 정확한가?
13. 수정 카드가 있을 경우 최종 ZIP과 미리보기에 실제로 교체되었는가?

---

## 9. Preview and delivery rules
- 카드별 원본 PNG를 제공한다.
- 전체 PNG를 하나의 ZIP으로 묶어 제공한다.
- 가능하면 채팅 내 이미지 갤러리/캐러셀 미리보기를 우선한다.
- 별도의 외부 미리보기 사이트를 만들지 않는다.
- 커스텀 클릭·스와이프 UI가 실제 환경에서 지원되지 않으면 지원한다고 주장하지 않는다.
- 빠른 전체 검수를 위해 별도의 contact sheet/overview 이미지를 만들 수 있으나, 이는 **게시용 파일이 아니다**.

## 10. Instagram caption guidance
게시 캡션은 카드 내용을 그대로 반복하지 않는다.

권장 구성:
- 실제 수업 장면 한 문장
- 카드의 핵심 관점 2~4문장
- 부모·교사에게 묻는 구체적인 질문 1개
- 필요하면 저장/공유 CTA 1개

예시 방향:
“아이의 ‘못해요’는 실력의 결론이 아니라, 아직 충분한 성공 경험이 쌓이지 않았다는 신호일 수 있습니다. 작은 도전과 반복, 다시 해보는 경험 속에서 ‘나도 할 수 있네’라는 기억이 생깁니다. 선생님과 부모님은 아이가 포기하려는 순간 어떤 말을 건네시나요?”
