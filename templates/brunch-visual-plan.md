## 자동 선택 체크
- [ ] 정확히 4개의 Visual인가?
- [ ] 표나 도식을 억지로 넣지 않았는가?
- [ ] 네 Visual의 역할이 서로 다른가?
- [ ] 본문을 그대로 반복하지 않는가?
- [ ] 각 Visual의 삽입 위치가 의미 전환점인가?
- [ ] 승인된 브런치 Visual 스타일을 따르는가?
- [ ] 동일 인물의 캐릭터 일관성이 유지되는가?
- [ ] 학생의 실제 외모를 특정할 수 없도록 익명화했는가?
- [ ] 표/도식도 따뜻한 카툰형 에디토리얼 스타일을 유지하는가?

## Output
최종 원고에는 다음 형식으로 표시한다.

`[VISUAL 01 · 삽화 삽입 — 설명]`

`[VISUAL 02 · 비교표 삽입 — 설명]`

`[VISUAL 03 · 도식 삽입 — 설명]`

`[VISUAL 04 · 삽화 삽입 — 설명]`

Visual 4개는 각각 독립 이미지로 제작하여 순서대로 스와이프 검토할 수 있게 출력한다.
