# Instagram Carousel Design Rules

## Purpose
《자존감 교실》의 인스타그램 캐러셀은 **따뜻한 공감 → 짧은 문장 → 여백 → 작은 위로 → 저장/공유**의 흐름을 시각적으로 구현한다.

## Visual identity
- 기본 바탕색은 **연주황/피치 계열 단색**을 우선한다.
- 전체 화면은 복잡한 배경, 그라데이션, 사진 콜라주를 피한다.
- 주조색 1개 + 짙은 브라운 계열 글자 + 최소한의 포인트 색만 사용한다.
- 화면의 40~60% 이상은 여백으로 남겨 호흡을 만든다.
- 손그림처럼 단순하고 둥근 선을 사용한다.
- 캐릭터는 작고 소박하게 배치하며 표정과 자세로 감정을 전달한다.
- 꽃, 구름, 풀, 하트, 창문, 책처럼 일상적인 작은 오브젝트를 최소한으로 사용한다.

## Character direction
- 특정 캐릭터의 얼굴·복장·고유 요소를 그대로 복제하지 않는다.
- **1950~60년대 단순 신문 카툰의 담백함**과 **따뜻한 손그림 애니메이션의 서정성**을 참고한다.
- 둥근 머리, 단순한 눈·입, 어린아이 같은 비율, 소박한 옷차림 등으로 독자적인 캐릭터를 만든다.
- 캐릭터가 주인공이 아니라 **문장의 감정을 보여주는 조연**이 되게 한다.

## Typography
- 짧은 문장, 큰 글자, 넓은 행간을 기본으로 한다.
- 한 장에 핵심 메시지 1개만 둔다.
- 한 문장은 가능하면 1~3줄로 제한한다.
- 굵은 강조는 한 장당 1~2곳만 사용한다.
- 말하듯 자연스럽고 따뜻한 한국어를 사용한다.

## Carousel structure
### 1. Hook
첫 장은 설명보다 감정을 먼저 건드린다.
예: “오늘도 애썼어요.” / “천천히 가도 괜찮아.”

### 2~4. Emotional progression
짧은 문장과 작은 장면으로 독자가 자신의 경험을 떠올리게 한다.
설교하거나 과도하게 설명하지 않는다.

### 5. Warm conclusion
한 문장으로 감정을 정리한다.
예: “오늘의 당신에게 수고했다고 말해주세요.”

### 6. Save/share CTA
강요하지 않고 자연스럽게 저장·공유 이유를 준다.
예: “힘든 날 다시 꺼내 보고 싶다면 저장해 두세요.”

## Content principles
- 정보형보다 **감정 보관형 콘텐츠**를 우선한다.
- 부모, 교사, 아이 모두가 자신의 경험을 투영할 수 있는 문장을 사용한다.
- 자존감을 ‘무조건 잘한다고 칭찬하기’로 표현하지 않는다.
- 위로는 현실을 부정하지 않고, 작은 행동이나 관점의 전환으로 이어진다.
- 마지막 장에는 구체적인 참여 질문 또는 저장·공유 CTA를 둘 수 있다.

## Production rules
- 기본 규격: **1080 × 1350px (4:5)**.
- 캐러셀의 모든 장은 동일한 색상·타이포그래피·여백 체계를 유지한다.
- 여러 장의 이미지를 한 파일로 합치지 않는다.
- 각 캐러셀 페이지는 **독립적인 PNG 파일**로 제작·관리한다.
- 파일명 예시: `carousel-01-hook.png`, `carousel-02-emotion.png`.
- 하나의 레퍼런스 시트가 있더라도 실제 게시용 파일은 반드시 장별로 분리한다.
- **사용자가 제공한 레퍼런스 시트에서 분리할 경우, 카드 경계/여백을 기준으로 정확히 한 장씩 crop한다. 인접 카드가 절대로 포함되지 않게 한다.**
- **모든 최종 카드의 pixel size는 동일해야 한다.**
- **Instagram 게시용 최종 산출물은 1080×1350px PNG로 통일한다.**
- 원본 레퍼런스의 비율이 4:5가 아니면, 내용을 찌그러뜨리지 않고 동일한 연주황 바탕으로 4:5 캔버스에 맞춘다. 텍스트·캐릭터가 잘리는 방식의 강제 crop은 피한다.
- 마지막 카드의 서명/브랜드 문구는 사용자가 지정한 정확한 표기를 사용한다. 이번 프로젝트의 표기는 **“북스타 써니샘”**이다.

## Preview and delivery rules
- 최종 산출물은 **총 11장**처럼 요청된 장수와 정확히 일치해야 한다.
- 카드별 PNG를 별도 파일로 제공하고, 전체 파일을 ZIP으로도 제공한다.
- 파일명은 업로드 순서를 반영해 `self_esteem_classroom_EP01_01.png`처럼 번호순으로 만든다.
- 미리보기에서는 여러 카드를 한 장의 게시용 이미지로 취급하지 않는다. 하나의 카드는 하나의 독립 이미지로 확인한다.
- 가능한 경우 채팅 UI가 제공하는 이미지 갤러리/캐러셀 표시를 우선 사용한다. 별도의 외부 미리보기 사이트를 만들지 않는다.
- 채팅 환경에서 실제 클릭·스와이프형 커스텀 UI가 지원되지 않는 경우, 지원하지 않는 기능을 지원한다고 주장하지 말고 카드별 이미지 미리보기와 개별 파일/ZIP을 제공한다.

## Quality check
게시 전 다음을 확인한다.
1. 첫 장만 봐도 감정이 전달되는가?
2. 각 장의 문장이 너무 길지 않은가?
3. 단색 바탕과 여백이 유지되는가?
4. 캐릭터가 메시지를 방해하지 않는가?
5. 특정 기존 캐릭터를 그대로 모방하지 않았는가?
6. 마지막 장에서 저장·공유 또는 구체적인 대화가 자연스럽게 이어지는가?
7. **모든 파일이 정확히 1080×1350px인가?**
8. **인접 카드가 섞이거나 겹쳐 들어가지 않았는가?**
9. **페이지 번호가 순서대로 정확한가?**
10. **한글 오타·누락·잘림이 없는가?**
11. **PNG가 정상적으로 열리고 손상되지 않았는가?**
12. **요청된 장수와 실제 파일 수가 일치하는가?**
