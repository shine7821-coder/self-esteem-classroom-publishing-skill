# 브런치 Visual Editorial 규칙

## 목적
《자존감 교실》 브런치 연재의 시각 자료는 장식이 아니라 글의 감정, 개념, 과정, 비교를 시각적으로 번역하는 편집 장치다.

> **글 속에서 말로 설명하지 않아도 느껴져야 하는 감정은 삽화로, 비교가 필요한 내용은 표로, 관계와 과정의 이해가 필요한 내용은 도식으로 번역한다.**

---

## 1. 기본 수량
최종 확정된 브런치 연재글 한 편에는 기본적으로 **정확히 4개의 Visual Asset**을 구성한다.

Visual Asset 유형은 다음 세 가지다.
- 삽화
- 표
- 도식

수량 4개만 고정하며, 유형의 비율은 고정하지 않는다.

허용 예:
- 삽화 4
- 삽화 3 + 도식 1
- 삽화 2 + 표 1 + 도식 1
- 삽화 1 + 도식 3

표나 도식이 글의 이해를 실제로 높이지 않는다면 억지로 넣지 않는다.

---

## 2. 유형 자동 선택 규칙
원고를 분석하여 각 구간의 편집 기능에 따라 가장 적절한 형태를 자동 선택한다.

### 삽화 우선
- 실제 교실 장면
- 아이의 표정, 행동, 대화
- 교사의 기억과 감정
- 관계의 변화
- 상징적이거나 은유적인 장면
- 글의 시작과 끝에서 정서적 몰입이 필요한 경우

### 표 우선
- A와 B 비교
- 잘못된 접근 vs 바람직한 접근
- 여러 특징의 병렬 정리
- 교사/부모의 언어 비교
- 여러 선택지의 차이를 한눈에 보여줄 때

### 도식 우선
- 단계와 순서
- 원인 → 과정 → 결과
- 교육 원리의 관계
- 반복되는 수업 구조
- 성장 과정
- 생각 또는 행동의 변화 흐름

### 핵심 원칙
> **본문을 그대로 복사해 이미지로 만들지 않는다. Visual은 본문의 이해·감정·기억을 확장해야 한다.**

---

## 3. 4개 Visual의 역할 분산
4개 모두 비슷한 장면이나 같은 기능을 반복하지 않는다.

기본 역할 예시는 다음과 같다.
1. **VISUAL 01 — Opening / Scene**: 실제 장면 또는 감정적 진입점
2. **VISUAL 02 — Understanding / Concept**: 핵심 개념의 비교 또는 설명
3. **VISUAL 03 — Change / Turning Point**: 변화, 전환, 성장 과정
4. **VISUAL 04 — Reflection / Aftertaste**: 마지막 성찰, 대표 문장의 여운

단, 원고 성격에 따라 역할 조합은 유연하게 바꾼다.

---

## 4. 본문 삽입 위치 표시
최종 원고에는 Visual이 들어갈 정확한 위치를 함께 표시한다.

표기 형식:
- `[VISUAL 01 · 삽화 삽입 — 간단한 설명]`
- `[VISUAL 02 · 비교표 삽입 — 간단한 설명]`
- `[VISUAL 03 · 도식 삽입 — 간단한 설명]`

Visual은 문단 사이의 의미 전환점에 배치한다.

권장 범위:
- Visual 01: 도입부 15~25%
- Visual 02: 35~45%
- Visual 03: 60~70%
- Visual 04: 80~90%

단, 비율보다 **문맥과 서사적 전환점**을 우선한다.

---

## 5. Visual 중복 방지
- 같은 교실 장면을 네 번 반복하지 않는다.
- 같은 핵심 문장을 네 번 다른 방식으로 되풀이하지 않는다.
- 같은 기능의 표와 도식을 중복해서 만들지 않는다.
- 네 개의 Visual은 각각 별도의 편집적 존재 이유를 가져야 한다.

좋은 흐름 예:
**장면 → 개념 → 변화 → 성찰**

---

## 6. 제작 순서
브런치 시각 자료는 글보다 먼저 만들지 않는다.

고정 워크플로:
1. 기존 연재 확인
2. 중복 방지 주제 설계
3. 저자 인터뷰 또는 위임 모드 적용
4. 필요시 과거 기록 검색
5. 원고 작성
6. 저자성 및 연재 중복 검수
7. 최종 원고 확정
8. Visual Point 4곳 선정
9. 삽화/표/도식 자동 결정
10. 원고에 `[VISUAL 01~04]` 위치 표시
11. Visual 4개 개별 제작
12. 대화창에서 스와이프 가능한 형태로 검토
13. 요청된 Visual만 개별 수정

---

## 7. 대화창 출력 규칙
최종 브런치 글 제작 시 산출물은 기본적으로 다음을 포함한다.
- 최종 원고
- `[VISUAL 01~04]` 삽입 위치
- 독립된 Visual 4개

Visual 4개를 한 장의 콜라주로 합치지 않는다.
각 Visual은 독립 이미지로 제작하고, 대화창에서 순서대로 스와이프하여 확인할 수 있는 형태로 제시한다.

수정 요청은 번호 단위로 처리한다.
예: `3번 도식만 수정해줘.`

사용자가 `글만 써줘`, `초고만 보여줘`라고 하면 Visual은 자동 생성하지 않는다.
최종본 제작 요청일 때 Visual 4개를 기본 산출물로 간주한다.

---

## 8. 브런치와 인스타그램의 관계
브런치 Visual은 인스타그램 카드뉴스를 그대로 복제하기 위한 것이 아니다.
브런치 Visual은 긴 글의 이해와 감정적 몰입을 돕고, 이후 인스타그램 캐러셀 소재로 파생할 수 있다.

브런치 Visual → Instagram Carousel 소재 후보

같은 핵심 아이디어를 플랫폼 역할에 맞게 다시 편집한다.

---

## 최종 품질 기준
각 Visual마다 다음 질문을 통과해야 한다.
- 이 Visual이 없을 때보다 글을 더 잘 이해하거나 느끼게 하는가?
- 본문을 단순 반복하지 않는가?
- 다른 3개 Visual과 역할이 겹치지 않는가?
- 《자존감 교실》의 따뜻한 시각 언어와 어울리는가?
- 삽입 위치가 글의 리듬을 깨지 않는가?
