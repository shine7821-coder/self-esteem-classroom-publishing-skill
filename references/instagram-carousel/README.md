# Instagram Carousel Reference

## Reference style
따뜻한 연주황 단색 바탕 + 짙은 브라운 텍스트 + 단순한 손그림 캐릭터 + 넓은 여백 + 짧은 위로 문장.

이 레퍼런스는 《자존감 교실》 인스타그램 캐러셀의 **시각적 기준점**이다.
