# Instagram Carousel Reference

## Primary approved reference
Instagram 카드뉴스 제작 시 아래 파일을 **우선 레퍼런스**로 사용한다.

- `approved-reference-design.md` — 현재 승인된 북스타/《자존감 교실》 카드뉴스의 시각 기준

핵심 인상:
- 따뜻한 연크림·연베이지·연주황 단색 계열 배경
- 검정/짙은 브라운 텍스트
- 오렌지 포인트
- 왼쪽 위 브라운 원형 페이지 번호
- 넓은 여백
- **Charlie Brown(찰리브라운)을 기본 주인공으로 일관되게 사용**
- 필요 시 **Snoopy(스누피)** 를 함께 배치
- 카드마다 얼굴 비율, 의상, 선 느낌, 색감을 유지해 동일한 캐릭터로 보이게 제작
- 짧고 감정이 분명한 한국어 문장
- 1080×1350px, 4:5 세로형

## Character continuity
새 카드 또는 수정 카드 제작 시 기존 승인 이미지를 레퍼런스로 사용한다.

우선 비교 항목:
- Charlie Brown의 둥근 머리와 앞머리 컬
- 노란 셔츠 + 검은 지그재그 패턴
- 검은 반바지, 노란 양말, 갈색 신발
- 얼굴선과 검은 윤곽선 굵기
- Snoopy의 흰 몸, 검은 귀·코, 크기 비율

표정과 자세는 장면마다 달라질 수 있지만, 전체 시리즈가 **같은 Charlie Brown과 Snoopy의 연속 장면**처럼 보여야 한다.
