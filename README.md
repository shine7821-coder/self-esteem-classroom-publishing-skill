# self-esteem-classroom-publishing-skill

《자존감 교실》의 **출판 계획 + 플랫폼 연재 전략 + 참여형 교육 콘텐츠 운영 규칙**을 담은 스킬입니다.

## 핵심 문장
> **실력은 건강한 자존감 위에 세워진다.**

## 목표
책을 완성하는 동시에 브런치, 인스타그램, 블로그, 쓰레드에서 교육 독자 공동체를 구축합니다.

## 콘텐츠 선순환
교육철학 → 실제 교실 사례 → 성취 경험 구조 → 교수법/팁 → 활용 자료 → 독자 적용 → 댓글/후기 → 공동체

## 폴더
- `strategy/`: 출판 및 연재 전략
- `templates/`: 반복 사용 가능한 콘텐츠 템플릿
- `rules/`: 브랜드 목소리와 운영 규칙

## 대표 콘텐츠
- 자존감 교실 이야기
- 오늘 바로 써보세요
- 자존감 교실 수업 팁
- 성취 경험 레시피
- 실제 수업 자료
- 이번 주 자존감 챌린지
