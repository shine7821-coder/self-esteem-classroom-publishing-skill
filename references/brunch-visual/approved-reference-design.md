# Approved Brunch Illustration Reference

## Reference source
사용자가 대화에서 제공한 승인 레퍼런스 이미지를 브런치 삽화의 시각 기준으로 사용한다.

현재 GitHub 연결은 텍스트 파일 편집 중심이므로 원본 이미지 바이너리 자체는 이 문서에 포함하지 않는다. 실제 제작 시 대화에 업로드된 승인 레퍼런스가 제공되어 있으면 해당 이미지를 우선 참조한다.

## Extracted visual characteristics
승인 레퍼런스에서 유지할 핵심 특성:
- 간결하고 깨끗한 카툰 선화
- 둥글고 친근한 인물 비율
- 얼굴 디테일을 최소화한 표현
- 부드러운 미소와 은은한 홍조
- 따뜻하고 안정적인 관계성
- 복잡하지 않은 포즈
- 절제된 디테일과 넓은 여백
- 밝은 크림/화이트 바탕과 웜 브라운 계열 인물 색감
- 필요할 때만 선명한 포인트 색상 사용
- 사진적 사실감보다 에세이 삽화다운 만화성

## Mood keywords
**warm / gentle / friendly / simple / cartoon / editorial / soft relationship / spacious**

한국어 키워드:
**따뜻함 / 친근함 / 단순함 / 부드러움 / 카툰 / 교육 에세이 / 관계 중심 / 여백**

## Use rule
새로운 브런치 삽화는 레퍼런스의 특정 구도나 인물을 복제하지 않는다.
대신 위 특징을 일관된 《자존감 교실》 Visual DNA로 재해석한다.

같은 연재에서 반복 등장하는 써니샘 캐릭터는 얼굴형, 헤어스타일, 신체 비율, 의상 분위기, 선 굵기와 색감을 일관되게 유지한다.
