# 《자존감 교실》 블로그 글

이 폴더는 《자존감 교실》의 교육 철학, 실제 수업 사례, 부모·교사에게 도움이 되는 실천적 내용을 블로그용 글로 정리해 저장합니다.

## 글 목록
1. [결과보다 과정이 훨씬 중요하다 — 완벽보다 끈기가 더 큰 힘이 되는 이유](01-결과보다-과정-완벽보다-끈기.md)

## 저장 규칙
- 블로그 공개용 완성 원고를 저장합니다.
- 실제 수업 사례를 중심으로 쓰되 학생의 개인정보는 보호합니다.
- 브런치 연재와 동일 문장을 그대로 복제하기보다 블로그 독자에게 맞게 실용성과 설명을 강화합니다.
- 글이 추가될 때 이 목록도 함께 업데이트합니다.
